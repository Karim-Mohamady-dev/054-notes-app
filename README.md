# نوتلي — تطبيق ملاحظات

تطبيق ملاحظات ثنائي اللغة (العربية RTL والإنجليزية LTR).

## المميزات
- إنشاء وتعديل وحذف الملاحظات مع العنوان والنص والوسوم
- مجلدات (افتراضية ومخصصة) وتصفية بالمجلد أو الوسم
- بحث فوري في العنوان والنص والوسوم
- ملاحظات مفضلة، ترتيب حسب الأحدث أو الأقدم أو العنوان
- عرض شبكة أو قائمة، نسخ الملاحظة، وتنزيلها كملف نصي
- حفظ كل شيء في localStorage

## التشغيل
```bash
npm install
npm run dev
npm run build
```
